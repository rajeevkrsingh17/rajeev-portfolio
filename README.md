## ✨ Features & Highlights

- **🌓 Dynamic Dual Themes (Dark & Light Mode):**
  - Instant animated theme switcher (Sun ☀️ / Moon 🌙) with `localStorage` state persistence.
  - Dark luxury aesthetic (`#09090B` with warm bronze `#B38A64` accents) & crisp light editorial theme (`#FAFAFA`).
- **🎨 Interactive Case Study Modals:**
  - In-depth architectural overviews, technical breakdowns, metrics, and technology pills.

  - Lenis smooth scroll lock and `Escape` key shortcuts.
- **🏆 Achievements Showcase:**
  - Highlighting cybersecurity leadership training at **WNS**, **100+** analytical problems solved (DSA/SQL), and **5+** production AI/Backend projects.
- **⚡ Performance & Smooth Motion:**
  - Built with Next.js 14/16 App Router, React 19, and Framer Motion micro-animations.

## 💻 Local Development Setup

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/rajeevkrsingh17/rajeev-portfolio.git

# Enter project folder
cd rajeev-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
